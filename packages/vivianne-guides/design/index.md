# Design

The look of a document is the user's to decide: follow their direction (style, colours, fonts, references, brand) first. These guides are the craft for carrying it out well, and the fallback when they leave it open. Read what the task needs.

| Guide | What it covers |
|---|---|
| [typography](typography.md) | Typefaces and pairings, the type scale, line length, spacing, numerals. |
| [color](color.md) | Neutrals, one accent, contrast, dark pages, brand colours. |
| [layout](layout.md) | Spacing, margins, grids, composition, and page sizes for every output. |
| [data](data.md) | Choosing charts, directing attention, numbers, tables. |
| [writing](writing.md) | Titles that say the point; copy that fits the design. |
| [formats/pdf](formats/pdf.md) | Reports, letters, one-pagers, CVs, invoices. How to call `create_document`. |
| [formats/slides](formats/slides.md) | Decks, as PowerPoint or PDF. |
| [formats/docx](formats/docx.md) | Word documents people will edit. |
| [formats/xlsx](formats/xlsx.md) | Spreadsheets people will work in. |
| [formats/graphics](formats/graphics.md) | Posters, covers, social images, cards. |
| [checklist](checklist.md) | The review before handing anything over. |
| templates/ | `cv`, `invoice`, `letter`, `poster`, `social`: finished HTML/CSS to adapt. |
